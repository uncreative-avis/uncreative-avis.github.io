# why switch from neocities to github pages?
Neocities is a great platform for indie web stuff and I'm so glad I chose it for hosting my site (completely free!) when I was completely new to web development, but it's got some issues that make it annoying for my use cases.

For example: the way Neocities handles caching CSS and JS is annoyingly persistent, making it difficult to push big changes unless you set something up to handle caching, like [cache busting](https://petrapixel.neocities.org/coding/cachebusting).

And besides limitations with Neocities, I'm just not super active in indie web spaces, as much as I'd like to be. 

**TL;DR:** I love Neocities and indie web, but Pages is just more suited towards me.
